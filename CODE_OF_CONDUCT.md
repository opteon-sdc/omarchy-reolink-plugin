# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work.
Harassment and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainer through a
[GitHub Security Advisory](https://github.com/opteon-sdc/omarchy-reolink-plugin/security/advisories/new)
or by contacting [@opteon-sdc](https://github.com/opteon-sdc) on GitHub.
Reports are handled confidentially.
